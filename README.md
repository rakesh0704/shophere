# 🛒 ShopHere

ShopHere is a full-stack e-commerce web application developed using Spring Boot, MySQL, HTML, CSS, and JavaScript. The application provides a complete online shopping experience with secure authentication, product browsing, cart management, wishlist functionality, checkout, and order tracking.

---

### Authentication

- Logout Functionality

## ⚙️ Setup and Installation

### 1. Clone Repository

```bash
git clone https://github.com/rakesh0704/shophere.git
```

### 2. Navigate to Project

```bash
cd shophere
```

### 3. Configure MySQL

Update application.properties:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/shophere
spring.datasource.username=root
spring.datasource.password=your_password
```

### 4. Run the Application

```bash
mvn spring-boot:run
```

### 5. Open Browser

```text
http://localhost:8080
```
